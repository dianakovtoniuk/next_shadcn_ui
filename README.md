# Support Me

A dashboard application built with Next.js and shadcn/ui. It includes a landing page, login and sign-up flows, and a responsive admin dashboard with charts and a data table.

## Features

- Landing page with a light/dark theme toggle
- Login and sign-up pages with form validation (React Hook Form + Zod)
- Responsive dashboard layout with a sidebar on desktop and a drawer on mobile
- Employee and team statistics with interactive charts
- Employees data table with a loading skeleton

## Tech Stack

- [Next.js 14](https://nextjs.org/) (App Router)
- [React 18](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/) and Radix UI
- [React Hook Form](https://react-hook-form.com/) and [Zod](https://zod.dev/)
- [Recharts](https://recharts.org/)
- [TanStack Table](https://tanstack.com/table)
- [Lucide](https://lucide.dev/) icons

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm

### Installation

```bash
git clone https://github.com/KovtoniukDiana/support-me-course.git
cd support-me-course
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production build

```bash
npm run build
npm run start
```

## Scripts

| Command         | Description                      |
| --------------- | -------------------------------- |
| `npm run dev`   | Start the development server     |
| `npm run build` | Create a production build        |
| `npm run start` | Run the production build         |
| `npm run lint`  | Lint the code with ESLint        |
